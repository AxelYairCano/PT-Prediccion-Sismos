# 🌍 Estimación de Sismos mediante Redes Neuronales

Este proyecto utiliza técnicas de **Machine Learning** y análisis de datos históricos para identificar patrones y realizar predicciones sobre la actividad sísmica en diferentes regiones del mundo, con un enfoque particular en zonas de alta sismicidad como **Tokio** y **Chile**.

## 🚀 Descripción del Proyecto

El objetivo principal es procesar catálogos sísmicos (1964-2020) para entrenar modelos predictivos que ayuden a entender mejor el comportamiento tectónico. Se incluyen análisis exploratorios de datos (EDA) y la implementación de una red neuronal para la estimación de magnitudes o frecuencias.

## 📊 Características Principales

* **Análisis Multiregional:** Scripts específicos para el estudio sísmico de Japón y Chile.
* **Procesamiento de Datos:** Limpieza y estructuración de catálogos sísmicos en formato CSV.
* **Modelado:** Implementación de redes neuronales con Python (TensorFlow/Keras).
* **Visualización:** Generación de gráficos predictivos y comparativas históricas.

## 📁 Estructura del Repositorio

* `redNeuronal.py`: Script principal con la arquitectura del modelo.
* `Proyecto_2(Chile)`: Script basado en el articulo de Chile.
* `Proyecto_2(Tokio)`: Script basado en el articulo de Tokio.
* `prediccionSismos.py`: Lógica para la inferencia y manejo de datos.
* `Graficos - Predictivos/`: Carpeta con los resultados visuales del análisis.
* `catalogo_sismos.csv`: Dataset utilizado para el entrenamiento.
